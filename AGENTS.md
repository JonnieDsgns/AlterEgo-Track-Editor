# Contributor entry point

Read docs/CAPABILITIES.md, docs/TECHNICAL_AUDIT.md, docs/BACKLOG.md and docs/ACCEPTANCE.md before implementation. Track Workshop 0.10.1 is baseline; active 0.11.0 is incomplete reference material. Blender minimum is 4.5; maintain tested compatibility results.

Preserve native unknown data, stable IDs, exact selectors, transform/normal/UV conventions and dependency graphs. Never fabricate native layouts or equate parser round trips with game acceptance. Assignment moves assets; duplication is explicit. All variants and agreed systems remain public V1 scope.

Keep original sources immutable. Do not launch the game, write its installation, invoke EGO GameDatabases Editor, bypass integrity systems or run upstream deployment scripts. Use private workspace outputs; user performs game validation. This project is asset authoring, not live engine hooking.

No game-derived assets, raw binary inputs, private research databases, credentials, machine paths or local fixtures in commits. Build/test artifacts belong under ignored build/. Preserve licenses and provenance before integrating external code. Update the technical audit/backlog and record precise verification scope after changes.
